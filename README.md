# VisionRPA-agent

VisionRPA-agent is a work-in-progress project focused on enabling computer task automation from a single natural-language command, with no prior automation flow setup required.

## Basic web interface

A minimal webapp interface is included so a user can describe work (for example: shopping for an item, sending an email, or other repetitive tasks) in one prompt.

### Run locally

Open the file below in your browser:

- `/home/runner/work/VisionRPA-agent/VisionRPA-agent/index.html`
